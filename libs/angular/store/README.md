# `@ibenvandeveire/ngx-store`

This Angular package provides utilities and abstractions for Redux workflows and Angular Signal stores.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/ngx-store` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed component-level API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Running Unit Tests

Run `nx test store` to execute the unit tests.
