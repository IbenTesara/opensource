# `@ibenvandeveire/ngx-i18n`

This Angular package provides a lazy-loaded modular approach to translations, language management guards, and translation resolvers.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/ngx-i18n` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed component-level API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Running Unit Tests

Run `nx test i18n` to execute the unit tests.
