# `@ibenvandeveire/ngx-core`

This Angular package provides core functionality and foundational abstractions for the other `@ibenvandeveire` Angular packages.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/ngx-core` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed component-level API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Running Unit Tests

Run `nx test core` to execute the unit tests.
