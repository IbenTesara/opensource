# `@ibenvandeveire/ngx-cookies`

This Angular package provides a wrapper and utilities for [CookieConsent V3](https://cookieconsent.orestbida.com).

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/ngx-cookies` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed component-level API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Running Unit Tests

Run `nx test cookies` to execute the unit tests.
