# `@ibenvandeveire/types-authentication`

This package provides TypeScript type definitions for authentication state, user permissions, and security scope models.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/types-authentication` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Building

Run `nx build authentication` to build the library.

## Running Unit Tests

Run `nx test authentication` to execute the unit tests via [Jest](https://jestjs.io).
