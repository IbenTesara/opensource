# `@ibenvandeveire/core`

This JavaScript package provides foundational core types and utilities.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/core` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Building

Run `nx build core` to build the library.

## Running Unit Tests

Run `nx test core` to execute the unit tests via [Jest](https://jestjs.io).
