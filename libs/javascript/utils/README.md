# `@ibenvandeveire/utils`

This JavaScript package provides utility functions for common JavaScript/TypeScript tasks.

## Documentation

Full documentation, usage examples, and API reference for `@ibenvandeveire/utils` are available on the [OpenSource Wiki](https://github.com/IbenTesara/opensource/wiki).

Detailed API documentation is also available via the [Compodoc Documentation](https://ibentesara.github.io/opensource/).

## Building

Run `nx build utils` to build the library.

## Running Unit Tests

Run `nx test utils` to execute the unit tests via [Jest](https://jestjs.io).
